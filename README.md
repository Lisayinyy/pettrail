# 宠迹 PetTrail

[在线体验](https://lisayinyy.github.io/pettrail/)

养宠成长记录与社区的可交互产品原型：一个 `index.html`，没有后端、没有构建步骤，数据保存在当前浏览器的 `localStorage`，页面预置了两只宠物的演示数据。

这是「爪印日记」（[pawprint](https://github.com/Lisayinyy/pawprint)）之前的概念验证，用来确定信息架构和核心流程；真实账号、云端同步和家庭共管在 pawprint 里实现。

## 原型里能做什么

- **首页**：宠物档案、健康管理分、到期提醒、一键记录。
- **健康**：体重曲线（含品种成年参考区间）、疫苗、驱虫、就诊用药，可导出文本版健康档案。
- **时间线**：所有记录按月汇成成长时间线，自动补生日和相伴天数里程碑，可生成成长报告并分享到社区。
- **宠友**：按城市、距离、品种、年龄给预置宠友打匹配分，含同城活动报名和模拟对话。
- **社区**：话题筛选、发帖、点赞、评论，日常可同步进时间线。

宠友、活动和自动回复是写在页面里的演示数据，匹配分是页面内的规则打分，没有真实用户或模型调用。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

也可以直接双击 `index.html`。桌面端左侧说明栏里的「重置演示数据」会清掉本地改动。

## 结构

`index.html` 自上而下：样式 → 页面骨架 → 工具函数与日期处理 → 演示数据 `seed()` 与本地存储 → 提醒和健康分规则 → 五个标签页的视图 → 表单与弹层。
